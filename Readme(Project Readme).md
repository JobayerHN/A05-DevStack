# Dev Stack – Technology Stack Builder

## Description
Dev Stack is an interactive web application designed to help developers and technical leads explore, compare, and assemble their ideal software development stacks. Users can seamlessly browse through frontend, backend, database, and DevOps tools to build and manage a custom tech stack for their next project.

## Technologies Used
- **Frontend Framework:** React, TypeScript, Vite
- **Styling & UI:** Tailwind CSS, DaisyUI
- **Icons & UI Utilities:** React Icons, React-Toastify
- **Deployment:** Netlify

## Features
- **Dynamic Stack Management:** Add or remove technologies across categories with real-time stack counter updates and a single-click clear functionality.
- **Instant User Feedback:** Integrated Toastify notifications that provide immediate visual confirmation whenever an action (add, remove, or clear all) is performed.
- **Asynchronous Data Handling:** Smooth loading experience powered by React Suspense with optimized fallbacks for seamless technology data fetching.
